# Установка 0.2.5

1. WordPress → Плагины → Добавить плагин → Загрузить плагин.
2. Выбрать `oberhub-v6-0.2.5.zip` → Установить → «Заменить текущий загруженным».
3. Если плагин не активен, активировать OberHub V6 Search Extension.
4. Открыть `/ru/search/?q=пицца`, затем нажать «Показать ещё».

Не удалять плагин перед заменой. Не повторять импорты 988/activities/life, не пересобирать индексы. Core остаётся 0.2.3. Настройки Groq и текущие данные сохраняются.

Откат: таким же способом заменить addon сохранённым ZIP 0.2.4. Core-модуль автоматически вернётся к предыдущему источнику.

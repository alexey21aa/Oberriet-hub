# Changes

## 0.2.0 — recovery and expanded knowledge release

- Adds distinct knowledge types and locally hosted weighted/typo-tolerant retrieval, without a mandatory paid generation API.
- Expands the curated source-backed corpus and multilingual retrieval phrases; release counts are generated from the final seed and distinguish facts, routes and aliases.
- Preserves operator-only editing, checked provenance, bounded waste dates and local email preparation.
- Adds a private resumable content import with validation, CSV round trips and native record editing.
- Adds opt-in on-device answer rephrasing with deterministic fallback; no per-query paid API is required.
- Adds architecture, hosting cost evidence and explicit privacy/deployment boundaries.

External publication and connector operations are reported separately in the handover. This entry does not claim that a GitHub repository, public host or WPVibe connection was created merely because local implementation exists.

## 0.1.0 — initial MVP

- Four languages; municipality services and contacts; locality navigation, waste/calendar/ICS, local editable German letters.
- Source registry, administration, retention controls, TOTP integration and WordPress browser verification tooling.

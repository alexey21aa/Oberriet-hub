WordPress существует на https://oberriethub.ch; WPVibe подтверждает Connected/Verified. Проверка site_info показывает активную Extendable 2.1.9, отсутствие oberhub-core, oberhub-theme и Vibe AI/WPVibe. WP-CLI пока возвращает 404 отсутствующего wpvibe/v1 route. Вход wp-admin показывает «Invalid login details», поэтому развёртывание не выполнено. GitHub подтверждает аккаунт alexey21aa; список доступных подключению репозиториев пуст. Браузер GitHub требует входа и показывает «Incorrect username or password»; создание oberriet-hub не подтверждено. Разрешение на создание уже получено; нужен действующий вход, а не повторное согласование создания. Платежей нет.

По данным владельца, домен зарегистрирован, Swizzonic Web Hosting Starter активен с trial до 01.11.2026, PHP 8.4, 50 GB, 5 MySQL DB, root /www. Эти параметры панели хостинга не проверялись данным запуском. MySQL поддерживается проектом; отдельный MariaDB dump не требуется: таблицы создаёт WordPress/dbDelta, записи загружаются из существующего seed.

Сохранённый MVP восстановлен без пересоздания: ZIP 52 836 269 байт, SHA-256 c940e9ff6a63906831638da7a9258402a76084686f96d8cb442101a2c52c7c7c; проверены все 3926 ZIP entries, ошибок нет. Git bundle содержит полную историю, main 9a978f758de01dffbc9bc8e207f6c3c6f164b4e0. Установочные ZIP theme/core/Two Factor также проверены.

Данные: 364 отдельные записи услуг/сценариев, 2548 маршрутов service+task и ответов, 5143 canonical intents (2595 простых/редакционных и 2548 составных целей), 71344 aliases, 293 источника, 35 учреждений/отделов и 35 контактов. Это не 2548 отдельных муниципальных услуг. Численные минимумы достигнуты. Каждая составная цель соединяет две задачи и ссылается ровно на два существующих ответа; новых услуг или фактических ответов она не добавляет.

Работают четыре языка, лёгкий responsive frontend, страницы услуг/тем/местностей/контактов/организаций/FAQ, source links и даты, гибридный детерминированный поиск с typo tolerance, locality/source weights и пагинацией. Native AI adapter необязателен, без API-оплаты и автоматической загрузки модели; реальная локальная модель здесь недоступна, проверен adapter/fallback. Стандартный поиск от него не зависит.

Календарь включает подтверждённые события и мусор/картон, ICS; отходы ограничены 2026 годом. Composer работает локально, copy/mailto без серверной отправки/хранения имени, адреса и текста. Неизвестные реквизиты получателя не заменяются случайным контактом.

Админка: native CPT, JSON editor и multilingual provenance, редакционные статусы, источники, CSV/JSON import/export, duplicates/schema/date checks, source link checks, bulk review/trash, оператор/организация/ответственное лицо/телефон. Большой импорт порциями с сохранением прогресса; success после индекса. TOTP и nonce/capability controls, приватные журналы с purge/retention.

В комплекте: готовый WordPress root, theme/core/Two Factor ZIP, source и данные, восстановленный Git bundle, README, deploy/admin/security/privacy/backup инструкции, QA evidence и previews. Данные владельца, хостинга и секреты отсутствуют.

Для развёртывания нужны действующие входы WordPress и GitHub, установка бесплатного Vibe AI из официального WordPress каталога и повторная проверка доступа WPVibe, затем импорт существующей темы/плагина/базы. Для публичной эксплуатации нужны настоящие реквизиты оператора и личные TOTP/recovery codes. Перед запуском проверить MySQL/HTTPS/cache/cron/backup на действующем сервере. Окончательные локальные тесты и границы доказательств приведены в QA_REPORT.md; 112 baseline проверок не являются production QA текущего сервера.
